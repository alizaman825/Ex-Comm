# Test cases

Manual test cases for the report (`docs/PROJECT_BRIEF.md` requires at least 20, as a table with ID, feature, steps, expected result, actual result, pass/fail).

**Actual Result and Pass/Fail are intentionally left as "Pending" below.** They have not been run yet in this session, and results are not invented — run each case against a live instance (local `npm run dev` on both `backend` and `frontend`, or the deployed URLs) and fill in what actually happened plus Pass/Fail.

Setup notes for whoever runs these:
- Demo login: `demo@excomm.pk` / `demo1234` (seeded automatically on first run).
- "Live" search cases assume Daraz/PriceOye are reachable from your network; if the app is in demo mode (`DEMO_MODE=true`) or a store is temporarily blocking requests, the search still works but the banner/behaviour differs — note that in Actual Result rather than treating it as a failure.
- AliExpress/eBay/Amazon checks are on-demand (button on the search page) and optional — eBay needs `EBAY_CLIENT_ID`/`EBAY_CLIENT_SECRET`, Amazon needs `BRIGHTDATA_API_KEY` configured in `backend/.env`; if unset, the expected result is a graceful "could not check" message, not a crash.
