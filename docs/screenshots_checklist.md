# Screenshots checklist

Screens for the report. Screenshots are generated by Playwright into `docs/screenshots/` (desktop 1440×900, full page) against the real backend in demo mode with sample data.

**Regenerate:** from `frontend/`, run `npx playwright test e2e/screens.spec.ts --project=desktop` (builds the app, starts the backend and frontend, writes the PNGs).

**Demo login:** `demo@excomm.pk` / `demo1234` (button "Try the demo account" on the login page).
